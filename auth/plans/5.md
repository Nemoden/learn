
• Project Idea

  - Build a “Serverless Team Files + Messaging Hub”: upload/share files, chat-style
    notifications, user auth, analytics; IaC from day 1 with SAM; Python Lambdas; deploy
    every sprint.

  Sprint Plan (feature-first, each deployable)

  - Sprint 0: Hello API via SAM — sam init Python/API template; add /health; deploy; learn
    SAM packaging, roles, sam deploy.
  - Sprint 1: Auth baseline — Cognito User Pool + Hosted UI; Lambda authorizer; API
    Gateway routes require JWT; MUST-KNOW: token scopes, CORS with auth, minimal IAM for
    authorizer.
  - Sprint 2: File upload — S3 bucket + presigned PUT from Lambda; API POST /files/upload-
    url; MUST-KNOW: API GW 10MB limit, CORS, S3 SSE, signed URL TTL; CloudWatch logs for
    Lambda.
  - Sprint 3: File listing/metadata — DynamoDB table for file records; Lambda writes
    metadata post-upload; API GET /files; MUST-KNOW: DDB PK/SK design, TTL for temp
    records, Lambda timeout/memory tuning.
  - Sprint 4: Notifications — SNS topic triggers fan-out; SQS queue for async workers;
    Lambda subscribes to SQS to post messages (e.g., “file ready”); MUST-KNOW: DLQ,
    visibility timeout, idempotency keys.
  - Sprint 5: Custom domain + edge — Route 53 record + API Gateway custom domain +
    CloudFront cache for static assets (SPA) from S3; MUST-KNOW: ACM cert in us-east-1,
    cache invalidations, CORS with CDN.
  - Sprint 6: Observability — CloudWatch metrics/alarms on Lambda errors & latency;
    structured JSON logging; X-Ray tracing on API/Lambda; MUST-KNOW: alarm actions,
    sampling.
  - Sprint 7: Containers path — Add one API route backed by Fargate service (ECS on
    Fargate) behind an ALB target for heavier jobs; ECR for image; VPC basics (subnets,
    NAT, SGs); MUST-KNOW: task roles vs execution roles, health checks.
  - Sprint 8: Data services — Add RDS Postgres (for relational data) alongside existing
    DDB; Lambda in VPC to query; MUST-KNOW: connection pooling (RDS Proxy), VPC endpoints,
    secrets in Secrets Manager/KMS.
  - Sprint 9: IaC maturity — Refactor SAM template modularity; add CloudFormation stack
    outputs/exports; Org-ready: parameterize envs, tags, cost allocation, least-priv IAM;
    MUST-KNOW: change sets, stack drift.

  Rhythm per sprint

  - Goal: single feature live.
  - Services: only what’s needed above.
  - Steps: update SAM template → sam build/sam deploy → hit API → verify logs/metrics.
  - Keep Python Lambda handlers + CLI equivalents for each new AWS interaction.


• Project: Serverless “Team Notebook” SaaS — users sign up, create notebooks, add notes,
  share read-only links. Build with SAM from day 1; each sprint ships a deployable feature
  and layers in new AWS services.

  - Sprint 1: Hello API + IaC
      - Goal: Deploy GET /health via API Gateway + Lambda using SAM.
      - Services: SAM/CloudFormation, Lambda, API Gateway, CloudWatch Logs.
      - Must-know: SAM template anatomy, sam build/deploy, stages, CloudWatch log
        inspection.
  - Sprint 2: Auth & Users
      - Goal: Cognito user pool + sign-up/sign-in; protect GET /me.
      - Services: Cognito (user pool, app client), API Gateway authorizer, IAM basics.
      - Must-know: JWT claims mapping, token expiration, API Gateway authorizer config,
        CORS.
  - Sprint 3: Notes CRUD (DynamoDB)
      - Goal: POST/GET/PUT/DELETE /notes scoped to user.
      - Services: DynamoDB (PK/SK), Lambda, IAM least privilege.
      - Must-know: PK design, conditional writes, TTL, error handling, Lambda timeouts/
        memory.
  - Sprint 4: File Attachments (S3 + presigned URLs)
      - Goal: POST /notes/{id}/upload-url returns presigned URL; client uploads directly.
      - Services: S3, Lambda, API Gateway, KMS SSE.
      - Must-know: Presigned URL limits, object ACLs, CORS, API Gateway 10MB payload limit,
        S3 bucket policies.
  - Sprint 5: Sharing & Edge
      - Goal: Public read-only link per note served via CloudFront with S3 origin.
      - Services: CloudFront, S3 static assets, Route 53 for custom domain.
      - Must-know: Cache behaviors, invalidations, HTTPS certs (ACM), DNS records.
  - Sprint 6: Notifications & Async
      - Goal: On share creation, send email; on big imports, queue processing.
      - Services: SNS (email), SQS (buffer), Lambda triggers, Dead-letter queues.
      - Must-know: Idempotency keys, retry/backoff, event shaping.
  - Sprint 7: Images & Container Workloads
      - Goal: Convert uploaded images to thumbnails via ECS/Fargate or Lambda container
        image; store results.
      - Services: ECR, ECS/Fargate (or Lambda container), S3 events.
      - Must-know: Task roles vs execution roles, sizing tasks, registry auth, cold starts
        for container Lambdas.
  - Sprint 8: DB for Reporting (RDS)
      - Goal: Nightly ETL from DynamoDB to RDS for admin reports.
      - Services: RDS (Aurora Serverless v2), Lambda (scheduled), VPC subnets/SGs, KMS.
      - Must-know: VPC networking for Lambdas, connection management (RDS Proxy optional),
        backups.
  - Sprint 9: Observability & Ops
      - Goal: Add metrics/alarms/dashboards, tracing, and org guardrails.
      - Services: CloudWatch metrics/alarms/logs insights, X-Ray, AWS Organizations SCPs,
        KMS key policies.
      - Must-know: Structured logging, high-cardinality pitfalls, alarm fatigue, SCP vs
        IAM.

  Each sprint updates SAM template, deploys, and validates via API/CLI. You’ll touch all
  listed AWS services in-context, with repetition across sprints to deepen understanding.

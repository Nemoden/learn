# Data Warehousing

My data warehousing learning journey with Claude Code.

Focus: building an analytics pipeline on AWS — DynamoDB + Lambda events → Kinesis → Iceberg/Parquet on S3 → Athena → QuickSight.

## Slash commands

- `/learn <project>` — resume guided learning from a project's plan.md
- `/til <thing>` — capture an aha moment to `learnings.md`
- `/know <fact>` — save a reference fact to `knowledge.md`
- `/later <topic>` — park a tangent in `to-learn.md`
- `/review` — spaced-repetition quiz on accumulated learnings
- `/adjacent <project>` — browse adjacent tech / alternatives reference (anti-tunnel-vision)
